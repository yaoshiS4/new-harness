State: rawQuery "", query "" (folded, debounced), categoryId "all", provider "all", bucket "all", page 1, online true (tracks navigator.onLine + online/offline events), errorNonce 0.

  3. Filter (AND): category, provider, bucket, and if query: every query token must be a prefix of some token in name OR any prevName OR provider OR category pool.
  4. Paginate: PAGE_SIZE 25; pageCount = max(1, ceil(total/25)); page clamped.
  5. notFound = total===0 && query!==""; emptyFilter = total===0 && query==="".
  6. Every filter change and every committed query resets page to 1. Picking a chip in NotFoundResolver clears query + bucket + provider and sets that category.
