/* ── reduced motion ──────────────────────────────────────────────────────── *
 * motion.css zeroes --dur-* app-wide, which kills the TRANSITION but not the
 * transform — a reduced-motion user would still get an instant jump. Every
 * transform above is switched off here, explicitly, exactly as the rail does.
 * There is no JS-driven motion on this page, so `usePrefersReducedMotion` has
 * nothing to gate: the contract is honoured where the motion actually lives. */
@media (prefers-reduced-motion: reduce) {
  .featured,
  .featured:hover,
  .playCta,
  .playCta:hover {
    transform: none;
    transition: none;
  }
}

6. States

Featured hover scale/border; CTA hover darker gold + scale; focus-visible 2px #6ea8ff offset 2px on .playCta (and .soonCard, which is disabled and unfocusable). Coming-soon cards disabled (no hover). While playing, the hub stays rendered underneath the overlay.

7. Motion

.featured transform/border-color 200ms; .playCta background-color/transform 200ms (ease-standard). Reduced motion: transforms and transitions none.
