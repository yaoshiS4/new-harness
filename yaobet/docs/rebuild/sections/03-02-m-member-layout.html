WidthLayout
375Single column. MemberSidebar renders FIRST, full width (hero card → wallet card → 2-up action cards → 12-tile grid → logout), then the page content below it with a 16px gap. The whole sidebar sits above the content on every member route, so content starts well below the fold (inference: ~800px down).
768Same single-column stack (breakpoint is 992). Bottom tab bar hidden from 768 (track S).
1024Two columns: sticky 304px rail (top: calc(72px + 48px + 16px) = 136px) + fluid column, 16px gap. Column width = frame width − 304 − 16 − any QuickActionRail reservation (track S reserves a rail column from 1024px; see #s-shell).
1440Same as 1024; frame capped at 1424px centered.
The rail is position: sticky but has no max-height/overflow; its natural height (≈ hero 170 + wallet 150 + action cards 130 + grid 4×86+3×8+34 ≈ 400 + logout 56 + gaps, inference ≈ 950px) exceeds a 900px viewport, so on short screens the bottom of the rail (logout) is reachable only by scrolling to the page end.

MemberSidebar — the member left rail

1. Purpose — The player sees their identity card (avatar initial, name, tier ribbon, ID with copy, membership progress), a wallet card (balance + Nạp/Rút), two action cards (points store, task center), a 12-tile icon menu and a logout button.

10. Behaviour & a11y — active-item logic

  1. On mount a useEffect stores window.location.hash without "#" in state and subscribes to hashchange.
  2. For each tile: split href on "#" → [mPath, mHash]. isSection = mPath === "/tai-khoan" && mHash !== "" (only the Bảo mật tile). onAccount = pathname === "/tai-khoan".
  3. If isSection && onAccount: active when mHash === hash. Otherwise active when m.href === pathname (exact string match; no prefix matching, hash ignored for other tiles).
  4. lit = m.id === "security" && user.verified adds .tileActiveGold regardless of route (it does NOT set aria-current).
  5. Element choice: when isSection && onAccount the tile is a native <a href="#bao-mat"> (so hashchange fires and AccountSections swaps panels); otherwise a next/link Link.
  6. Result per route: /vi-tien → tile 1 active; /tin-nhan → tile 6; /gioi-thieu → tile 7; /tai-khoan#bao-mat → tile 8 active; /tai-khoan (no hash), /tai-khoan#ho-so, /dai-ly → no tile active.
  7. Wallet buttons link to /vi-tien#deposit / /vi-tien#withdraw; WalletTabs reads the hash (see #m-wallet-tabs).
  8. Copy ID: navigator.clipboard.writeText(user.memberId); success → copied=true for 2000ms.
  9. The decorative .heroSheen/.walletSheen/.cardSheen spans and the avatar are aria-hidden; the unread dot is aria-hidden (no text alternative for the unread state).
