Acceptance checklist

A rebuild passes only when every item below holds. Run them in order; later checks assume earlier ones pass.

1. Static checks

  1. npm run lint:tokens exits 0, and npm run lint:tokens:self-test exits 0 (the self-test seeds violations and must detect them).
  2. npm run lint and npx tsc --noEmit exit 0.
  3. npm run build succeeds and lists every route in the route inventory.
  4. No CSS module reads a raw ramp variable (--gold-*, --cta*, --font-body, --font-num, --text-on-gold); components read semantic tokens only. The lint enforces this as assertion A2.
  5. Every [data-brand] block declares only --brand-* variables (assertion A1), and --focus-ring, --win, --loss, --error are standalone constants (assertion A3).

2. Routes

  1. Each URL in the route inventory returns 200 in the dev server, signed out and signed in, except the four redirect routes below, which answer 307 from redirect().
  2. /bao-mat and /lich-su land on /tai-khoan; /hoan-tra lands on /khuyen-mai; /game-han-che lands on /cuoc-hop-le?tab=han-che with the restricted tab selected.
  3. All 9 verticals render under /[vertical]; any other segment renders the vertical not-found page.
  4. /khuyen-mai/pr1 to pr8 render; an unknown id behaves as the promotion section specifies.
  5. Routes that have a loading.tsx show their skeleton while loading.

3. Visual comparison

  1. Capture each route at 375 × 812 and 1440 × 900, device pixel ratio 1, reduced motion, full page, in both guest and tiered states (recipe below).
  2. Compare against the reference screenshots with the same file name. Section order, column count, spacing rhythm, colour, type weight and wrapping must match. Small differences in mock-randomised values are acceptable only where the data section says the value is random or time-based.
  3. Check the intermediate widths 768 and 1024 against each route's composition notes, especially the breakpoints where the header, category rail, bottom tab bar and member sidebar change.
  4. /vip uses the luxury palette, not the default obsidian surfaces.

4. Copy

  1. Every Vietnamese string in the copy tables appears verbatim, with diacritics, case and punctuation unchanged.
  2. No Vietnamese glyph falls back to a system font: fonts load with the vietnamese subset (check ữ, ặ, ở in headings and buttons).
  3. Money and numbers use the formatters from Lib and mock data, never ad-hoc formatting.

5. States, motion and accessibility

  1. For every component, exercise each state listed in its States row: hover, focus-visible, active, selected, disabled, loading, empty, error, signed out and signed in. The style deltas must match.
  2. Keyboard: every interactive element is reachable with Tab, shows the focus ring, and modals and sheets trap focus and close on Escape as their sections specify.
  3. Motion: durations and easing match the motion tokens; with prefers-reduced-motion: reduce the reduced behaviour described for each animation applies.
  4. Mock auth: every fresh load starts in tiered, register in the auth modal leads to level-0, log in leads to tiered, a reload returns to tiered, and the DEV toggle is absent from a production build.

Screenshot capture recipe

The reference set was produced with Playwright against next dev -p 3107. Each state is set through the home-page DEV toggle (cycled until its label reads Hội viên or Khách), then routes are visited client-side so the in-memory session survives; a final check confirms the state did not drift. Use the same script to capture your rebuild, then compare file by file.

Capture script (Node, ESM) 
import fs from 'fs';
import { chromium } from 'playwright';

const BASE = 'http://localhost:3107';
const OUT = './shots';
const ALL = ['/', '/casino', '/slots', '/sports', '/khuyen-mai', '/khuyen-mai/pr1',
  '/tai-khoan', '/vi-tien', '/tin-nhan', '/gioi-thieu', '/dai-ly', '/bao-mat',
  '/vip', '/tier', '/cau-lac-bo', '/cua-hang', '/ve-so', '/bo-suu-tap', '/bo-suu-tap/cua-toi',
  '/cuoc-hop-le', '/game-han-che', '/hoan-tra', '/lich-su', '/ho-tro', '/tro-giup',
  '/tai-app', '/phong-cach', '/dev/collection-ports'];
const GUEST = ['/', '/khuyen-mai', '/tai-khoan', '/vi-tien', '/vip', '/cua-hang', '/ve-so', '/gioi-thieu'];
const PLAN = [{ state: 'tiered', label: 'Hội viên', routes: ALL }, { state: 'guest', label: 'Khách', routes: GUEST }];
const VIEWPORTS = [{ name: 'm375', width: 375, height: 812 }, { name: 'd1440', width: 1440, height: 900 }];
const slug = (r) => (r === '/' ? 'home' : r.slice(1).replace(/\//g, '__'));
const log = (...a) => console.log('[shots]', ...a);

async function setState(p, label) {
  await p.goto(BASE + '/', { waitUntil: 'networkidle', timeout: 60000 });
  await p.waitForTimeout(800);
  await p.getByRole('button', { name: /chuyển trạng thái đăng nhập/ }).click();
  const cycle = p.locator('button[class*="cycle"]').first();
  const cur = cycle.locator('[class*="stateLabel"]');
  for (let i = 0; i < 4 && (await cur.innerText()).trim() !== label; i++) { await cycle.click(); await p.waitForTimeout(250); }
  const got = (await cur.innerText()).trim();
  if (got !== label) throw new Error(`state ${got} != ${label}`);
  await p.getByRole('group', { name: /Trạng thái đăng nhập/ }).getByRole('button', { name: 'Đóng' }).click();
  await p.waitForTimeout(300);
  return got;
}

async function checkState(p, label) {
  await p.evaluate(() => window.next.router.push('/'));
  await p.waitForURL((u) => u.pathname === '/', { timeout: 30000 });
  await p.waitForTimeout(600);
  await p.getByRole('button', { name: /chuyển trạng thái đăng nhập/ }).click();
  const got = (await p.locator('[class*="stateLabel"]').first().innerText()).trim();
  await p.getByRole('group', { name: /Trạng thái đăng nhập/ }).getByRole('button', { name: 'Đóng' }).click();
  return got === label ? 'ok' : `DRIFT ${got}`;
}

const b = await chromium.launch();
const manifest = [];
try {
  for (const vp of VIEWPORTS) {
    for (const plan of PLAN) {
      const ctx = await b.newContext({ viewport: { width: vp.width, height: vp.height }, deviceScaleFactor: 1, reducedMotion: 'reduce' });
      const p = await ctx.newPage();
      log(vp.name, 'state set:', await setState(p, plan.label));
      for (const r of plan.routes) {
        try {
          await p.evaluate((route) => window.next.router.push(route), r);
          await p.waitForURL((u) => u.pathname === r, { timeout: 20000 }).catch(() => {});
          await p.waitForLoadState('networkidle', { timeout: 60000 });
          await p.waitForTimeout(1800);
          const file = `${vp.name}-${plan.state}-${slug(r)}.jpg`;
          await p.screenshot({ path: `${OUT}/${file}`, fullPage: true, type: 'jpeg', quality: 72 });
          manifest.push({ route: r, state: plan.state, viewport: vp.name, file, landed: new URL(p.url()).pathname + new URL(p.url()).search });
          log('saved', file, '->', p.url());
        } catch (e) { log('FAIL', vp.name, plan.state, r, e.message); }
      }
      log(vp.name, plan.state, 'final check:', await checkState(p, plan.label));
      await ctx.close();
    }
  }
} finally {
  await b.close();
  fs.writeFileSync(`${OUT}/manifest.json`, JSON.stringify(manifest, null, 2));
  log('DONE', manifest.length);
}

The cycle button is located by a class name containing cycle. CSS Modules hash class names, so keep the module class named cycle in the dev toggle's stylesheet, or change the selector. Redirect routes are captured at their destination URL.
