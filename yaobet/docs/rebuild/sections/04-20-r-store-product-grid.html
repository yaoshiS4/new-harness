ProductGrid (+ filter tabs)

1. Purpose

Filterable grid of reward cards; owns the redeem dialog and the guest gate.

2. Source

src/components/store/ProductGrid.tsx, ProductGrid.module.css (shared with ProductCard)

3. Structure

status==="loading" → ul.grid aria-busy  li.cell × max(cols||2, computeGridFill(cols,1,2)+1)  TileSkeleton
status==="error"   → ErrorState title "Không tải được cửa hàng" message "Không tải được danh sách quà đổi điểm. Vui lòng thử lại." onRetry=load
items.length===0   → EmptyState icon gift title "Cửa hàng trống" message "Hiện chưa có sản phẩm nào để đổi điểm."
else:
  div.tabs role=tablist aria-label="Cửa hàng điểm"
    button.tab[.tabActive] role=tab aria-selected  "Tất cả" | "Voucher tiền" | "Sản phẩm"
  ul.grid (ref → useGridCols)
    li.cell per visible product → ProductCard(product, points=effectivePoints, allowed, paused, onRedeem)
  selected && RedeemDialog(product=selected, points=effectivePoints, paused, onClose)

6. States

Tab active by colour only (also scales on hover). Tabs have no :focus-visible rule (browser default). Filter is client-side by category; "Voucher tiền" shows 6, "Sản phẩm" 5, "Tất cả" 11. An empty filtered list renders an empty ul (no empty state).

7. Motion

.tab color/border-color/transform 200ms ease-standard; reduced motion: transition none, hover transform none.

8. Copy

"Tất cả" (All), "Voucher tiền" (Cash vouchers), "Sản phẩm" (Products); error/empty strings above.

9. Data

Product shape: src/lib/types.ts lines 187–233.

10. Behaviour & a11y

Card CTA → onRedeem: guest → promptAuth(); member → setSelected(product) mounts RedeemDialog. Dialog close → selected null (unmount).

status starts "ready" and load() is only called from the ErrorState retry, so the TileSkeleton loading grid and the ErrorState are unreachable; a server fetch failure is swallowed into [] and shows "Cửa hàng trống" instead of an error. The tabs claim role="tab" with no tabpanel.
