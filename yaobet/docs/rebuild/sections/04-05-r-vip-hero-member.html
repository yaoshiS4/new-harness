6. States

Static. If nextTier is undefined (nextTierIndex out of range) the whole progress block is omitted. pct clamped 0–100.

7. Motion

.fill width and .knob left transition 300ms --ease-entrance (only visible if values change; they never do — constants).

8. Copy

"Điểm" (label, shown uppercase), "Tiến độ cược lên hạng sau", "{pct}%", next tier name, "›", "{n} điểm để lên {next}". Tier names via copy bag; "♛" crown glyph.
