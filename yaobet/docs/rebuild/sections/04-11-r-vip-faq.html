6. States

Closed default (openFaq = −1). Clicking an open row closes it; clicking another switches. Hover chevron scale(1.1) (open: rotate(180deg) scale(1.1)). Focus-visible: outline 2px #6ea8ff offset −2px.

7. Motion

item background/border 200ms; ::before opacity 200ms; question colour 200ms; chevron transform 300ms + border/background 200ms; answer max-height 300ms (all ease-standard). Reduced motion: no hover scale; open chevron stays rotated.
