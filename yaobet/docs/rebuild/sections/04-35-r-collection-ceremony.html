RewardCeremony (exchange confirm + reveal ceremony)

1. Purpose

Exchange flow for a completed set: a confirmation that spells out which cards will be spent, then a short ceremony where the set's cards gather and a gold seal draws over them, ending on the receipt.

2. Source

src/components/collection/RewardCeremony.tsx, ceremony.module.css

Ceremony state machine

beat reducer: gather → seal → receipt (terminal)
timers: gather 900ms → seal; seal 700ms → receipt   (useEffect on [beat, reduced])
reduced motion (matchMedia at render) → settled immediately, no timers
settled = reduced || beat === "receipt"; receipt content needs settled AND grant (else "Đang chuyển vào ví…")
CSS by data-beat:
  gather:  cards spread  translateX(i·26px) rotate(i·5deg), origin 50% 120%
  seal/receipt: cards stack translateX(i·2px) rotate(i·0.8deg) scale(.94) (transition 780ms cubic-bezier(0.22,0.61,0.36,1));
                seal opacity 0→1 (260ms ease), scale .86→1 (420ms); ring draws 620ms cubic-bezier(0.4,0,0.2,1);
                tick draws 380ms after 380ms delay
  receipt[data-ready=true]: opacity 0→1, translateY(6px)→0 over 320ms ease

6. States

confirm → (Xác nhận) ceremony pending → receipt / error. Example confirm for "5 Trung vệ thép" with each card held once and all five also counted elsewhere: "dùng hết 5 thẻ … 0/5"; collateral "Đội hình Liverpool — mất 3 thẻ" (van Dijk, Konaté, Robertson) and "11 Siêu sao — mất 2 thẻ" (van Dijk, Gabriel) — only if those cards are held.

7. Motion

As above. Reduced motion: no transitions, seal strokes drawn instantly (dashoffset 0), hover scale removed, component skips to the receipt.

9–10

Overlay focus trap / Esc. Stage aria-hidden; receipt text is plain (not a live region).

Beat timer starts during the confirm phase. RewardCeremony stays mounted from confirm to ceremony (no key change) and its timer effect does not check impact, so the 900 + 700 ms beats elapse while the confirm dialog is open. If the player takes >1.6 s to press "Xác nhận", the gather/seal animation is skipped and the receipt appears at once (and can momentarily read "lần đổi thứ 0" before the refresh lands). Copy says the set "returns to 0/N" even when spare copies keep some cards (it returns to 0/N only if no spares).
