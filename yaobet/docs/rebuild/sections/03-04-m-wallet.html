Amount input behaviour: on change, strip all non-digits; if any digits, amountText = formatVnd(Number(digits)) (e.g. typing "150000" shows "150.000 ₫") and amount = Number(digits); else both cleared. Tapping a chip sets both. A chip is active (Pill active) only when amount exactly equals its value. Serial/PIN inputs keep digits only.

Validation: NONE on the amount for any rail — "Tôi đã chuyển" works with an empty amount; the card rail requires only non-empty serial and PIN. Submit when !allowed calls promptAuth({ action: "deposit", isFirstDeposit }) (cannot happen in practice because the guest branch hides the form).

Status states: idle → pending (any rail). Pending "Quay lại" returns to idle with rail/amount state preserved (same component instance). Copy memo: clipboard success → button label "Đã sao chép" for 2000ms.
