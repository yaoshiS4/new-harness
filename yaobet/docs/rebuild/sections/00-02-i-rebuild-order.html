Rebuild order

  1. Stack and project. Next.js 16.2.9 (App Router, Turbopack dev), React 19.2.4, TypeScript 5, ESLint 9 with eslint-config-next. No UI library, no Tailwind, no Bootstrap: plain CSS Modules plus one global stylesheet. Path alias @/* → ./src/*. next.config.ts is empty. See Stack.
  2. Tokens, themes and the token lint. Recreate every custom property exactly, then the brand and theme blocks, then scripts/token-lint.mjs so violations fail early. See Tokens and Themes and brands.
  3. Typography, motion, reset. Fonts load through next/font/google with the vietnamese subset. See Typography, Motion, Reset and globals.
  4. Root layout. <html lang="vi" data-brand="yaobet" data-theme="obsidian">, the mock auth provider, the app shell, footer and quick-action rail. See Root layout.
  5. Primitives in src/ui (17 components). Build these before any screen; every route composes them. See UI primitives.
  6. Lib and mock data. Formatters, the VIP maths, and every mock dataset the screens read. Screens render mock data only; there is no API. See Lib and mock data.
  7. Shell, then routes. Header, category rail, bottom tab bar, footer and overlays come next, then the routes in the order of the sections that follow: home and discovery, member area, then VIP and rewards.
  8. Verify with the acceptance checklist.
