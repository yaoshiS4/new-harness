ProductCard

1. Purpose

One reward: image with category tag, base-points coin badge and live cooldown chip; name, face value, withdrawal condition and a single state-driven CTA.

2. Source

src/components/store/ProductCard.tsx; styles in ProductGrid.module.css.

6. States

  • Affordable (member, base ≤ balance, stock > 0, not at floor): gold "Đổi ngay".
  • Not enough points: ghost disabled "Thiếu N điểm" (N = base − balance, VN grouping).
  • Disabled at limit (at_floor): ghost disabled "Hết lượt đổi"; cooldown chip still visible; image full colour.
  • Out of stock: tag becomes "Tạm hết", image opacity .4, ghost disabled "Tạm hết hàng" (applies to guests too).
  • Cooldown running (member only): chip bottom-left of image with live HH:MM:SS. When it reaches zero the Countdown fires onZeroState → nowMs re-read → running false → chip disappears and the branch returns to base.
  • Guest: no chip, never "Thiếu…", CTA gold "Đăng nhập để đổi" (except sold-out).
  • Image error: fallback tile (gift glyph + name).
  • Button hover/focus/disabled visuals: #f-ui-button (gold/ghost, size sm, fullWidth).

7. Motion

None on the card itself (Card variant hover per F). Countdown ticks every 1 s (reduced motion: single timeout to the deadline, no per-second tick).

9. Data

Card face never shows per-user data except the member's cooldown chip; the badge always shows basePoints (never the escalated cost). Values: formatVnd → "200.000 ₫"; formatCount → "1.000".

10. Behaviour & a11y

The whole card is not clickable; only the CTA. img alt = product name; fallback tile aria-label = name.

Header comment promises a "disabled-everywhere card face" when the program budget breaker is paused; paused is never read by ProductCard, so with DEMO_PAUSED the cards still say "Đổi ngay" and only the dialog changes. CSS ships unused .rollingSlot, .limitStatus*, .limitGlyph, .limitClock, .limitHelper (an older in-body limit status).
