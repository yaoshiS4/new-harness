TierLadder (/tier)

1. Purpose

Horizontal deck of the five legacy tiers with their rebate rate and perk lines, marking the member's current and locked tiers.

2. Source

src/components/vip/TierLadder.tsx, TierLadder.module.css

/* TierLadder — horizontal tier deck. Tokens only.
 *
 * RULING B1: every tier card is the SAME 168px box (and the same flex:1 1 0
 * share on desktop) regardless of tier. Rank is carried by POSITION in the
 * ladder and by the Card `active` border, never by size. There is deliberately
 * NO :hover transform here — these are display cards, not links or buttons, so
 * a hover scale would advertise an affordance that does not exist. */

.deck {
  display: flex;
  gap: var(--space-3);
  list-style: none;
  margin: 0;
  padding: 0;
}
.item {
  flex: 0 0 auto;
}

  display: flex;
  flex-direction: column;
  align-items: center;
  gap: var(--space-2);
  width: 168px;
  min-height: 100%;

  scroll-snap-align: start;
}

7. Motion

None (no hover transform by design).

8. Copy

"Hiện tại", "Chưa mở", "Hạng {n}", "Hoàn trả {x}%", perk strings above.

10. Behaviour & a11y

Scroller handles snap/peek (track F). Cards are non-interactive.

Rate "Hoàn trả 1%" for Bạc (1.0.toString() = "1") sits next to its perk line "Hoàn trả 1,0%".
