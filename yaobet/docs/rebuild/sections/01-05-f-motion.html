motion.css defines no keyframes. It is only the reduced-motion contract, inside @media (prefers-reduced-motion: reduce):

  1. :root { --dur-fast: 0ms; --dur-base: 0ms; --dur-slow: 0ms; }
  2. *, *::before, *::after { animation-duration: 0.001ms !important; animation-iteration-count: 1 !important; transition-duration: 0.001ms !important; scroll-behavior: auto !important; }

The second rule uses !important, so it overrides every literal duration in components as well (e.g. Skeleton's 1400ms, Button spinner's 700ms). Several components also apply their own reduced-motion overrides (listed per primitive), and JS animations gate on usePrefersReducedMotion() from src/lib/rg.ts.

JS motion in src/ui: the Odometer runs a 700ms requestAnimationFrame tween with easeOutCubic 1 - (1-t)^3. The Countdown ticks with a 1000ms setInterval. The Sheet tracks swipe-down live through an inline style.transform.

CSS-Module keyframe names are hashed per module, so fade in Modal and fade in Sheet are independent and never collide. A rebuild that uses global CSS must rename them.
Verbatim src/styles/motion.css
/* ============================================================================
 * Yaobet — global motion + reduced-motion contract (SPEC-02 §7, SPEC-04 1.2)
 * ----------------------------------------------------------------------------
 * The single, app-wide prefers-reduced-motion implementation. Because all
 * motion reads the --dur-* tokens, zeroing them here disables every
 * token-obeying animation with NO per-component opt-in (LOCKED — not
 * overridable per brand).
 *
 * Flat Design timing (tokens.css §7): 200ms is the default for colour /
 * opacity / border micro-interactions and 300ms is the ceiling, reserved for
 * larger transforms. Snappy and direct — nothing eases in slowly.
 * ==========================================================================*/

@media (prefers-reduced-motion: reduce) {
  :root {
    --dur-fast: 0ms;
    --dur-base: 0ms;
    --dur-slow: 0ms;
  }

  /* Decorative motion the duration-tokens alone don't reach: confetti,
   * odometer reels, auto-advancing carousels, count-ups → disabled; the
   * final truthful state is shown instantly. Components additionally gate
   * their own JS animation on this query (SPEC-03 F5). */
  *,
  *::before,
  *::after {
    animation-duration: 0.001ms !important;
    animation-iteration-count: 1 !important;
    transition-duration: 0.001ms !important;
    scroll-behavior: auto !important;
  }
}
