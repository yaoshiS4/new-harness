R1 · VIP — overview, routes and the luxury palette

Track R covers the VIP program (/vip, /tier, /cau-lac-bo), the points store (/cua-hang), the scratch-card lottery (/ve-so) and the card collection (/bo-suu-tap, /bo-suu-tap/cua-toi, /dev/collection-ports). Every route renders inside the global shell (#s-shell: header, category rail, bottom tab bar, QuickActionRail, auth modal). Primitives (Card, Button, Badge, Icon, Modal, Countdown, Tabs, Scroller, Skeleton, EmptyState, ErrorState, MoneyValue) are specified by track F (#f-ui-button and siblings); tokens by #f-tokens. This fragment gives every value the R-area components set themselves.

Two VIP systems coexist. /vip is a self-contained "luxury" rebuild (5 tiers Đồng→Kim Cương × 10 levels, data in src/lib/vip/*, components VipProgram tree, page-scoped .vipPalette). /tier is the legacy ladder page (5 tiers Tân thủ→Kim Cương, data in src/lib/mock/vip.ts, components CurrentTierCard/TierLadder/PrivilegeTable/PerkGallery/VipRules, app-canvas palette). They share no data and no tier names list. Rebuild them as two independent features.

Formulas (src/lib/vip/formulas.ts) — verbatim

/** Per-tier gift multiplier (bronze..diamond). */
export const GIFT_MULT = [0.6, 0.8, 1.0, 1.4, 2.0] as const;

/**
 * Promotion-gift amount ($) for a tier/level, rounded to the nearest $5.
 * @param tierIndex 0..4
 * @param level     1..10
 */
export function giftAt(tierIndex: number, level: number): number {
  return Math.round(((50 + (level - 1) * 25) * GIFT_MULT[tierIndex]) / 5) * 5;
}

/**
 * Scale a tier BASE value (a level-10 / 100% figure) down to a given level:
 * 82% at L1 → 100% at L10. Used for every rebate + weekly-cashback cell.
 * @param base  the tier's level-10 (100%) base value
 * @param level 1..10
 */
export function rate(base: number, level: number): number {
  return base * (0.82 + (0.18 * (level - 1)) / 9);
}

/** Alias for `rate` under the guideline's alternate name. */
export const rebateAtLevel = rate;

/** "$1,234" — gift display (thousands-grouped, no decimals). */
export function fmtGift(n: number): string {
  return "$" + n.toLocaleString("en-US");
}

/** "14%" — weekly-cashback display (whole percent). */
export function fmtCash(r: number): string {
  return Math.round(r) + "%";
}

/** "0.62%" — per-category rebate display (2 decimals). */
export function fmtRate(r: number): string {
  return r.toFixed(2) + "%";
}

GIFT_MULT = [0.6, 0.8, 1.0, 1.4, 2.0]. giftAt(t, l) = round(((50 + (l−1)·25) · GIFT_MULT[t]) / 5) · 5. rate(base, l) = base · (0.82 + 0.18·(l−1)/9). fmtGift → "$" + en-US grouping; fmtRate → 2 decimals + "%"; fmtCash → Math.round + "%".
