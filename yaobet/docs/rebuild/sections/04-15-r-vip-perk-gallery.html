PerkGallery (/tier)

1. Purpose

Grid of perk tiles (icon slot, name, "unlocks at tier N" badge, description), with a lock veil on perks above the member's tier.

2. Source

src/components/vip/PerkGallery.tsx, PerkGallery.module.css

3. Structure

perks.length===0 → EmptyState(icon gift, message "Quyền lợi theo hạng")
ul.grid
  li.item per perk
    Card(variant="tile").perkCard
      div.art aria-hidden  Icon gift 28 ; locked && span.mask  Icon lock 20
      div.body
        div.perkHead  span.perkName name · Badge(tone = locked?"neutral":"gold", subtle) "Mở từ hạng {n}"
        p.perkDesc  description
        locked && p.lockedNote  "Lên hạng để mở quyền lợi này."

5. Styles
