LevelTable

1. Purpose

6 benefit rows × levels 1–10 for the selected tier; members see their own level spotlighted in gold and levels above it dimmed/locked.

2. Source

Verbatim LevelTable.module.css
/* ============================================================================
 * Level table — 6 metric rows × 10 level cols of the SELECTED tier.
 * Sticky first col + sticky header + sticky corner; horizontal scroll.
 * Member CẤP-7 gold spotlight column; locked-ahead + above-tier dim/lock.
 * ==========================================================================*/
.scroller {
  overflow-x: auto;
  border-radius: var(--vip-radius-table);
  border: 1px solid var(--vip-hairline);
  background: var(--vip-panel-bg);
  -webkit-overflow-scrolling: touch;
}

/* RULING B1 — `table-layout: fixed` so all TEN level columns get exactly the
 * same width. Under auto layout the widths were content-driven and the current
 * (bold, spotlit) level came out widest: measured 74px against 70–71px for its
 * peers. A level that renders wider *because* it is the one you are on is a
 * size cue tied to standing, which is the pattern B1 rejects. Fixed layout also
 * makes CẤP 10 the same width as CẤP 1. min-width is raised so the equal share
 * still fits the widest cell ("1,000,000") without wrapping. */
.table {
  border-collapse: separate;
  border-spacing: 0;
  table-layout: fixed;
  width: 100%;
  min-width: 900px;
  font-family: var(--brand-font-num);
  font-variant-numeric: tabular-nums;
}

/* ---- shared cell chrome ---------------------------------------------------
 * EVERY cell reserves the same 1px side rules and the header row the same 2px
 * bottom rule, so the gold spotlight column is a pure COLOUR change with zero
 * layout shift — and all ten level columns stay geometrically identical
 * (ruling B1: never rank a level/tier by physical size). */
.th,
.td {
  padding: var(--space-3) var(--space-4);
  text-align: center;
  border-bottom: 1px solid var(--vip-hairline);
  border-left: 1px solid transparent;
  border-right: 1px solid transparent;
  white-space: nowrap;
  color: var(--vip-text-secondary);
  background: var(--vip-panel-bg);
  font-size: var(--t-sm);
}

tbody tr:last-child .td {
  border-bottom: none;
}

/* ---- sticky first column (metric labels) + corner ------------------------- */

  width: 200px;

  font-family: var(--brand-font-body);
  font-weight: var(--weight-semi);
  color: var(--vip-text-primary);

6. States

  • Guest: all cells plain; no locks.
  • Member, selected = own tier (Vàng): CẤP 7 column .spot (gold band, bold); CẤP 8–10 .dim with 🔒 under the numeral in the header; 1–6 plain.
  • Member, selected above own tier (Bạch Kim, Kim Cương): every level cell .dim; no lock glyphs.
  • Member, selected below own tier: plain.

7. Motion

None.

8. Copy

"CẤP"/"LEVEL", row labels (copy bag), values per the computed table in r-vip-lib.

9. Data

giftAt(selectedTierIndex, l), rate(tier.rebate.*, l), rate(tier.cash, l).

10. Behaviour & a11y

Horizontal scroll below 900px wide content (min-width 900). Sticky header is sticky relative to the scroller (which has no max-height), so vertically it never sticks in practice (inference).
