VipProgram (+ language toggle)

1. Purpose

The /vip page root: a warm-black luxury panel with a VI/EN toggle that holds the hero, tier deck, privileges, level table and FAQ.

2. Source

src/components/vip/VipProgram.tsx, VipProgram.module.css

4. Props / variants

No props. State: vipSel (default 2), vipLvl (default min(7+1,10) = 8), lang ("vi"). onSelect(i): vipSel = i; vipLvl = (i === 2) ? 8 : 1.

6. States

langBtn hover: scale(1.05), colour #f6e39a. Focus-visible: outline 2px solid --focus-ring #6ea8ff, offset 2px. Active button keeps gold fill on hover (and also scales 1.05). Logged-out vs logged-in: see structure.

7. Motion

langBtn: transform/background/color 200ms --ease-standard. Reduced motion: transform none.

8. Copy

"VI", "EN" (uppercased lang codes); aria-label "Language" (English, not localised). Section headings: see copy bag.

9. Data

TIERS, CURRENT_USER, CUR, CUR_LEVEL, FAQ_ITEMS, getVipCopy(lang) from @/lib/vip.

10. Behaviour & a11y

Lang toggle re-renders the whole subtree in the chosen language (FAQ, tier names, labels). Toggle state is not persisted (resets to VI on reload). Guest CTAs both call promptAuth() which opens the auth modal in login mode.

"Đăng ký ngay" (register) opens the auth modal in login mode — onRegister and onLogin are the same call (useRequireAuth().promptAuth() → openAuthModal({ mode: "login" })).
