Known discrepancies to reproduce

The current app has defects. A faithful rebuild reproduces them; fixing them is a separate decision. These are the most consequential, collated from the sections below, where each is specified in full. Items marked verified were re-checked against source while compiling this guide.

  1. Boot state is signed in. src/app/providers.tsx:19 mounts MockAuthProvider initialState="tiered" (verified). See Runtime and mock auth.
  2. Vertical lobbies are unreachable from the UI. Every category link points to /?v={id} (src/lib/mock/lobby.ts:34, verified), which the home page ignores; /[vertical] renders only when typed. See Vertical lobby.
  3. Header overflows below 1440 px. Measured in the browser: tier-1 is 623 px wide at a 375 px viewport, putting the bell and member menu off-screen; tier-2 (1384 px) is clipped below 1440. See Header.
  4. Right rail stacks under the main column between 1240 and 1423 px. The rail turns on at 1240 px but the two-column grid starts at 1424 px. See Right rail.
  5. --brand-logo is never read. Header and auth modal hard-code /assets/logo.svg, so a brand logo override has no effect (verified). 17 tokens are defined but unused. See Foundations: unused code.
  6. Emerald brand puts a gradient on the primary button. --brand-cta-grad becomes a gradient under the emerald brand and Button .primary reads it; the token lint does not catch literals. See Themes and brands.
  7. Wallet transfer shows a double currency sign. FundTransferPanel.tsx:148 appends ₫ after formatVnd(), which already ends in ₫ (verified). Other wallet defects: withdraw destination shows the house account, deposit amount is never validated, three of four wallet tabs are not keyboard-reachable. See Wallet.
  8. Member sidebar dead ends. Three items go to /hoan-tra (redirects to /khuyen-mai); Lịch sử goes to /lich-su (redirects to the profile, not history); /bao-mat lands on /tai-khoan without the security panel hash. See Member layout.
  9. Signed-out users see member data. Security panel, bank cards, crypto addresses, referral figures and message counts render mock member data with no auth check. See Member discrepancies.
  10. Duplicated and dead code. The Sheet primitive is unused; components/layout/_internal re-implements Countdown, Money, Overlay, focus trap and reduced-motion; 8 home components and 4 account components are dead. Rebuild only what renders, unless the unused sections say otherwise. See Foundations, Shell and home, Member.
  11. Comments contradict code. Many source comments describe older designs (hero slide count and colour, footer column count, field focus colour, Cinzel font, "no hard-coded Vietnamese strings"). This guide always follows the code.
  12. Two VIP systems disagree. /vip shows 5 tiers × 10 levels with up to 25% weekly cashback; /tier shows a different tier list at 0.6–1.5%. The /vip member view always shows the demo member, not the signed-in user. See VIP.
  13. The collection's rare guarantee is shown but not enforced. The pity counter is updated after each open (lib/collection/adapters/fixtures.ts:336), but the draw picks by weight only and never forces a rare (verified). See Collection logic.
  14. Collection and store state bugs. The exchange animation runs while its confirm dialog is open; returning to /bo-suu-tap can stop new opens and collide open ids; store cooldowns are fixed at server start; the store's error and loading states are unreachable and a failed fetch shows the empty state; the balance is not reduced after a redeem. See Collection and Store.
  15. Scratch card pays a consolation on every card and builds losers as near-misses. lib/mock/lottery.ts:54 and :218 (verified). Copy says Mua một tấm and Đã cộng vào số dư but there is no purchase or wallet call, and the development force-result bar ships in the player overlay. See Scratch card.
  16. /dev/collection-ports writes to the same saved collection data the player pages read. See Rewards: unused code.
