/* One message card on the --surface-2 sub-surface.
 *
 * The hairline is LOAD-BEARING, not decoration: --surface-2 #1a1a1a on the
 * panel's --surface #141414 measures 1.14:1, and the flat system bans the two
 * other separation mechanisms (shadow, card gradient). Without this border the
 * card had no edge at all. --border is the locked gold-tinted hairline and

States: unread card (wash + 3px gold edge + dot + bold subject, interactive) → read card (plain div, regular subject) after click. Mark all read → all cards read, button disappears, subtitle "Đã đọc tất cả". Delete all → empty EmptyState; actions vanish (hasItems false). Filtered empty → filtered EmptyState with reset. Reduced motion: transitions removed, hover transforms none.

Behaviour: all mutations are local React state (lost on navigation). The filter Dropdown is uncontrolled: choosing an option changes the filter but does NOT close the panel (ui/Dropdown closes only on trigger click, Esc or outside click — see #f-ui-dropdown).
