How to use this guide

This is an as-built specification of the Yaobet web app in apps/web. It is written for an agent that has no access to the repository and must rebuild the current UI so that it looks and behaves the same. It describes what exists today, including defects; it is not a redesign brief. Where the source has a bug or a token-contract break, the guide reproduces the behaviour and flags it in an amber callout so you can decide separately whether to fix it.

Rule of precedence. When two parts of this guide disagree, trust them in this order: (1) verbatim CSS and code blocks, (2) style and copy tables, (3) prose, (4) reference screenshots. Screenshots are taken at device pixel ratio 1 with reduced motion and cannot show hover, focus, motion or alternate states.

Conventions

--token
A CSS custom property from the token contract (Tokens). Wherever a style uses one, both the token and its resolved value are given.
Amber callout
A discrepancy: a literal value that breaks the token contract, a comment that disagrees with the code, a bug, or dead code.
Green callout
A rebuild tip or an ordering dependency.
(inference)
A statement deduced from the code rather than read directly. Everything else is fact.
(not found in source)
Something the template asks for that the app does not define. Do not invent it.
Copy tables
Vietnamese strings are verbatim, including diacritics and punctuation. The English column is a gloss for you, never shown in the UI.
