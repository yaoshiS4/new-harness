PrivilegeComparison (member)

1. Purpose

Two benefit cards — your current tier and a target tier — listing the four privileges with ✓/🔒 and a gold "MỚI" tag on newly gained ones.

2. Source

src/components/vip/PrivilegeComparison.tsx, PrivilegeComparison.module.css

3. Structure

div.wrap
  article.card
    header.head
      span.gem  style.background = left.acc   aria-hidden
      h3.cardTitle style.color = left.acc     left tier name
    ul.rows  (renderRows(left))
  div.arrow aria-hidden  "→"
  article.card.cardTarget
    header.head  gem + h3 (right tier)
    ul.rows  (renderRows(right, comparedTo=left))
    targetAboveCurrent && footer.footer
      span.lock aria-hidden "🔒"
      "{needWager} {right.unlock}"
renderRows: for PRIVILEGES idx:
  li.row[.rowLocked if !unlocked][.rowNew if isNew]
    span.marker.(check|lock) aria-hidden  "✓" | "🔒"
    span.rowLabel   privilege label
    isNew && span.newTag  "MỚI"
  unlocked = idx < tier.perks; isNew = comparedTo && idx >= comparedTo.perks && unlocked

4. Props

tiers, selected, currentTierIndex (2), currentLevel (7, ignored — void currentLevel), lang.
