PackStage (pack opening)

1. Purpose

A floodlit stadium with five foil packs: pick one, press "MỞ", the pack tears and the drawn card rises out.

2. Source

Pack-opening state machine

initial phase = last ? "revealed" : "idle"; picked = 2 (middle pack)
idle:      tap pack i → picked = i   (pick is ritual; it does not affect the draw)
           press MỞ → onOpen() → draw resolves (≈220ms latency) → `last` changes
on new last: phase = "tearing" (picked pack plays `tear`, others `.dim`), timeout 620ms → "revealed"
revealed:  card + line; press "MỞ TIẾP" → phase = "idle" then onOpen() again
opens = 0 or busy → CTA disabled (packs remain pickable while idle)

6. States

idle (picked pack enlarged/bright), tearing (packs disabled), revealed (card, "MỞ TIẾP"), disabled CTA when no opens. Reduced motion: no bob/sheen/rise/tear (tear → opacity 0 instantly), no hover scale.

7. Motion

See table; .info/.cta transitions 200ms ease-standard; .pack transitions transform/filter/opacity 320ms.

10. Behaviour & a11y

Packs are toggle buttons (aria-pressed). The reveal is not announced (no live region).

Packs use filter: brightness()/saturate() and CardArt ghosts use filter: grayscale(), while other modules (store, lottery) state a house-wide ban on any non-none filter. The ≥900 rule .info { right: max(...) } is dead (the buttons live in the positioned .chrome wrapper now), and its selector :not(.info) lets .chrome pick up max-width 780px. Five Foil SVGs repeat the ids pk/pkSheen. Stadium/foil colours are raw HSL/hex literals outside the token layer.
