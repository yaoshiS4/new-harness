## 2. Translation rules (binding)

| Guide CSS | Write | Never |
|---|---|---|
| `prop: var(--token)` with a §3.6 key | the mapped utility (`bg-surface`, `p-space-5`, `text-t-sm`, `rounded-pill`) | stock scale utilities (`p-4`, `text-sm`, `rounded-full`, `shadow-md`): after `--*: initial` they emit nothing |
| `z-index`, `transition-duration` tokens | `z-(--z-modal)`, `duration-(--dur-fast)` | `duration-150`, `delay-75` and every numeric duration or delay (amended) |
| `background:` shorthand or a gradient token | `[background:var(--x)]` | `bg-(--x)` (that emits `background-color`) |
| `background-image:` | `[background-image:var(--x)]` | |
| `transform:` | `[transform:scale(1.02)]` | `scale-*`, `rotate-*`, `translate-*`, `skew-*` (separate properties) |
| alpha or `color-mix(in srgb …)` | the arbitrary value written out literally | `/NN` opacity modifiers (they mix in oklab) |
| `linear-gradient`, `radial-gradient`, `conic-gradient` | `[background:…]` | `bg-linear-*`, `bg-radial-*`, `bg-conic-*`, `from-*`, `via-*`, `to-*` (amended) |
| `grid-template-columns: repeat(N, 1fr)` (amended) | `grid-cols-[repeat(N,1fr)]` | `grid-cols-N`, `grid-rows-N` (they emit `repeat(N, minmax(0, 1fr))`) |
| borders between children | plain border utilities on the children, as the guide does | `divide-*` (amended) |
| `@media (max-width:Npx)` | `max-420:`, `max-639:`, `max-900:`, or `[@media(max-width:Npx)]:` | `max-[Npx]:` (exclusive), `max-sm:` and the like |
| `@media (min-width:Npx)` | `min-[Npx]:` | `sm:`, `md:`, `lg:`, `xl:`, `2xl:` (rem, and reset anyway) |
| `:hover` | `hover:` (redefined to a plain `:hover`) | |
| `@media (hover:hover) and (pointer:fine)` + `:hover` | `hover-fine:` | |
| `@media (hover:hover)` + `:hover` | `[@media(hover:hover)]:hover:` | |
| `transition:` lists | `[transition:a_var(--dur-x)_var(--ease-y),b_…]` | `transition`, `transition-all`, `transition-colors`, `transition-opacity`, `transition-shadow`, `transition-transform`, `ease-in`, `ease-out`, `ease-in-out`, `ease-linear` (amended) |

These are the only renames (the original's only colliding names are `sweep`, `slideUp`, `fade`) | redeclaring a name anywhere in `src/` (`rebuild-rules` asserts every `@keyframes` name is unique) |
| literals (2px, 0.06em, 60ch) | arbitrary values `gap-[2px]` | |
| `box-shadow: var(--lift)` | `[box-shadow:var(--lift)]` | `shadow-*`, `ring-*`, `drop-shadow-*`, `backdrop-blur-*` |
| `!important` | only where the guide has it, listed per file in `scripts/rebuild-rules.allow.json`; never on animation or transition | `!` as an override tool, leading or trailing (PR-15 makes it unnecessary) |
| pseudo-elements with at most 3 declarations (amended, PLAN-GATE item 15) | `before:`/`after:` utilities with `before:content-['']` | |
| larger pseudo-elements, masks, clip-path, `:has`, descendant or compound selectors, `data-*` selectors, more than 3 declarations of art | plain CSS in the leaf's own partial (`src/ui/ui.css` or `src/styles/areas/<area>.css`), selectors kept (PR-02), no `@layer` wrapper (§1). | capture-script hooks | literal unstyled classes `cycle` and `stateLabel` (PR-08) | |
| `line-clamp: 2` tiles | the full set from ui-member T8 | `line-clamp-2` alone |

## 4. Mechanical rule gates (run by every leaf, written by F0) (amended)

Both scripts are zero-dependency Node ESM in `scripts/`, share one class-token extractor, and take file, directory or `dir/**` arguments: `[` and `]` are literal, braces are expanded, and an argument that matches 0 files is an error (exit 1, printing `argument matches no file: <arg>`, checked before any other input is read). Output: one `path:line: <rule-id> <token>` line per hit, then `RULES OK n files` / `CLASSES OK n tokens`; any hit exits 1.

**Class-token extraction** (`.ts`, `.tsx` only): string literals and template-literal static parts inside `className=`, `class=`, and the arguments of `cn(`, `clsx(` and `cx(`, split on whitespace; tokens containing `${` are skipped. The variant prefix is everything up to the last `:` at bracket depth 0; the utility is the rest. CSS custom properties, `.css` text and verbatim CSS in comments are never class tokens.

**`rebuild-rules.mjs` class rules** (anchored on the token or its utility, never substrings; `\|` in this table is a regex `|`, escaped for the table):

| id | matches | |
|---|---|---|
| R-bp | variant `(^\|:)(max-)?(sm\|md\|lg\|xl\|2xl):` | `max-639:` and `min-[768px]:` are clean |
| R-max-arb | variant `(^\|:)max-\[` | |
| R-transform | utility `^-?(scale\|rotate\|translate\|skew)(-\|$)` | `[transform:translate(-50%,-50%)]` is clean |
| R-bg-var | utility `^bg-\(--` | |
| R-gradient | utility `^(bg-(linear\|radial\|conic)-\|from-\|via-\|to-)` | |
| R-opacity | utility `^(bg\|text\|border\|fill\|stroke\|outline\|decoration\|accent\|caret\|placeholder\|divide\|ring\|shadow)-[^/\[]+/[0-9]+$` | `aspect-[16/9]`, `top-1/2` are clean |
| R-depth | utility `^(shadow\|ring\|inset-shadow\|inset-ring\|drop-shadow\|backdrop-blur)(-\|$)` | `[box-shadow:var(--lift)]` is clean |
| R-radius | utility `^rounded-full$` | |
| R-transition | utility `^transition(-(all\|colors\|opacity\|shadow\|transform))?$`, `^(duration\|delay)-[0-9]`, `^ease-(in\|out\|in-out\|linear)$` | `duration-(--dur-fast)` is clean |
| R-divide | utility `^divide-` | |
| R-grid | utility `^grid-(cols\|rows)-[0-9]+$` | `grid-cols-[repeat(3,1fr)]` is clean |
| R-important | token starts or ends with `!`, unless `file:line` is in `scripts/rebuild-rules.allow.json` | |

**Source rules** (all `.ts`, `.tsx`, `.css` text): `tailwind-merge`, `\.module\.css`.

**CSS rules**: in `src/ui/ui.css` and `src/styles/areas/*.css`, any `@utility`, `@apply`, `@custom-variant`, `@theme`, `@layer` or `@import` (R-css-at); in `src/ui/ui.css`, any `@keyframes` (PR-18); across all of `src/**/*.css`, a `@keyframes` name declared twice (R-kf-dup).

**Comment rules** (comment text only: `//…`, `/*…*/`, JSX `{/*…*/}`, in `.ts`, `.tsx`, `.css`; PR-27, PR-31): case-sensitive `\b(SPEC|GC|BR|UT|ST|FR|DEFECT|CASE|UC|NFR|AC|OD|SH|UIM|FC|REWARDS|ADR|RG)-[0-9]+\b|\bJ[0-9]+\b|\bWave [0-9]|\bruling [A-Z][0-9]+\b|\bPR-[0-9]{2}\b|\bleaf-[A-Z][0-9]`; case-insensitive `decree|nghị định|giấy phép|statute|regulat|licen[cs]|complian|pháp luật|thông tư`. Rendered copy is not scanned here (A11 scans everything; PR-32).

**`rebuild-rules --self-test`** prints one `seed` line per case and `SELF-TEST OK` only when every positive fires and every clean seed passes. Positives: one per rule id above, plus `Wave 3`, `J9`, `SPEC-02`, `Decree-174` in comments, and `@utility x {}` in a seeded area partial. Clean seeds, verbatim: the eight original token lines `--t-sm:`, `--t-num-lg:`, `--radius-sm:`, `--radius-md:`, `--radius-lg:`, `--shadow-2:`, `--gap-sm:`, `--card-pad-sm:` (orig `src/styles/tokens.css:76,84,104-106,122,144,151`), `transition:` in a `.css` file, and the class tokens `[transform:translate(-50%,-50%)]`, `[transform:scale(1.02)]`, `aspect-[16/9]`, `top-1/2`, `max-639:p-space-2`, `min-[768px]:p-space-2`, `grid-cols-[repeat(3,1fr)]`, `duration-(--dur-fast)`, `hover-fine:bg-surface`, `[@media(hover:hover)]:hover:bg-surface`, `cycle`, `stateLabel`, plus the rendered string `YB-668812` and a directory argument named `[vertical]`.

**`tw-unknown-classes.mjs`** (PR-23): compiles each unique class token with the installed `tailwindcss` `compile()` against the repo's real `src/app/globals.css`, and flags a token whose CSS is empty unless it is allow-listed. Allow-list: every class selector parsed from `src/ui/ui.css` and `src/styles/**/*.css` (area classes, `ui-*`), plus the fixed set `group`, `group/<name>`, `peer`, `peer/<name>`, `cycle`, `stateLabel`, `active`. `--emit <token>` prints the compiled CSS of one token (F1's `group-hover:` gate). `--self-test` compiles against its own seed CSS (a theme with `--*: initial` plus a seed file declaring `.ui-btn`), never against `src/`, prints one `seed + <token>: flagged` or `seed - <token>: clean` line per case, and prints `SELF-TEST OK` only when `p-4`, `text-sm`, `h-9` and `hover-any:x` are flagged and `cycle`, `stateLabel`, `ui-btn`, `group` and `active` are clean. (amended, plan re-gate items 6, 14, 22) The PM-authored F0 checks assert each of these seed lines, each `rebuild-rules` class-token rule on a fixture, and the zero-match message of both scripts.

Known limit: class strings built outside `className`/`cn()` (for example a lookup table of class names) are invisible to both scripts; frontend-qc covers them.

## Consequences

- Positive: every computed value is the guide's; the cascade follows the guide; the lint and the checklist still run; zero new runtime dependencies; every rule gate is token-anchored, so verbatim guide CSS never trips it.
- Negative: class strings are long and arbitrary-heavy; a typo is silent unless `tw-unknown-classes` catches it; class strings built outside `className`/`cn()` are not scanned.
- Alternatives rejected: CSS Modules (owner D2); `tailwind-merge` (a dependency, and it does not fix in-primitive specificity); keeping preflight and patching it (changes the UA heading sizes the guide relies on); substring rule gates (they fire on `--radius-sm:` and `transition:`, PLAN-GATE item 7).
