# SkillBank v2 (Harness² Recursive Architecture)

## Purpose
Store distilled, reviewed skills, failure lessons, and empirically validated task experience capsules in a hierarchy retrieved by PM, SkillOpt, Dreaming, Meta-Evolution, and Turn-1 Cue-Matched Injection (`pre_invocation_hook.py`).

## Layers

- `general/`: Stable skills that apply across projects and task types.
- `task-specific/`: Project or domain heuristics with a clear applicability boundary.
- `failure-lessons/`: Concise anti-patterns distilled from validated failures.
- `optimized/`: Current best validated skill documents promoted by SkillOpt or Level-2 reflection.

## Merge Criteria

SkillBank entries may be added or revised only when all criteria pass:

1. Evidence comes from validated traces, Oracle-reviewed outcomes, or explicit user-approved lessons.
2. The entry states when to activate and when not to activate.
3. The entry has a measurable success signal or adherence check.
4. The entry does not conflict with native runtime boundaries.
5. `codex_knowledge` memory or graph stores retain the evidence link.
6. `optimized/` entries are only replaced after strict held-out validation improvement and Oracle review.
7. Experience capsules must pass the deterministic **`NO_ENTRY` Gate** before writing to disk.

## Level-2 Inter-Task Experience Reflector & The `NO_ENTRY` Gate

At task teardown, `~/.gemini/antigravity/scripts/reflect-experience.py` inspects any task-level harness overlay (`.antigravity/task_harness/`) and session execution telemetry.

### Causal Verdicts
1. `helped`: Candidate harness/skill modifications produced measurable behavioral improvement without regressions.
2. `hurt`: Modifications increased tool errors, read strikes, loop warnings, or broke tests.
3. `no_observed_effect`: Behavioral delta was non-positive ($\le 0$) or identical to baseline.
4. `confounded`: Two or more unisolated edits occurred without an isolated behavioral probe (`unisolated_edit_count >= 2 and not isolated_probe`).

### The `NO_ENTRY` Anti-Hallucination Gate
To prevent memory bloat, contaminated feedback loops, and hallucinated heuristics, the reflector mechanically enforces:

```python
if (
    verdict in ("hurt", "no_observed_effect", "confounded")
    or confidence not in ("high", "medium")
    or not cue.strip()
    or not evidence.strip()
):
    return {"status": "NO_ENTRY", "verdict": verdict, "bytes_written": 0}
```

When `NO_ENTRY` triggers:
- Zero bytes are written to SkillBank or `registry.sqlite`.
- Any candidate overlay is reverted or discarded.

When `verdict == "helped"` and `confidence in ("high", "medium")`:
- The capsule is written to `~/.gemini/antigravity/skillbank/<layer>/<entry_id>/EXPERIENCE.md`.
- Executable harness files are preserved in `~/.gemini/antigravity/skillbank/<layer>/<entry_id>/harness/`.
- `~/.gemini/antigravity/skillbank/INDEX.md` is automatically refreshed.
- Overlay directory is cleaned up when `--cleanup-overlay` is specified.
